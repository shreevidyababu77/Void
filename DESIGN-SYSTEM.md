# VOID – Design System

| Color | Hex Code | Purpose |
|---|---|---|
| Primary | #20243A | Main headings and navigation |
| Secondary | #7966D8 | Buttons and highlights |
| Background | #F5F6FA | Page background |
| Surface | #FFFFFF | Cards and containers |
| Text | #252938 | Main text |
| Secondary Text | #6B7280 | Supporting text |
| Accent | #E6A23C | Points and rewards |
| Success | #2E9D68 | Success messages |
| Error | #D64545 | Error messages |

## 2. Typography

| Element | Font Size | Weight |
|---|---|---|
| Page Heading | 28–32px | Bold |

| Buttons | 14–16px | Semibold |
| Small Text | 12–14px | Regular |

## 3. Spacing System

The application uses a consistent spacing scale:

- 4px – Extra small
- 8px – Small
- 12px – Medium small
- 16px – Medium
- 24px – Large
- 32px – Extra large

## 4. Reusable UI Components

### Buttons
Used for actions such as creating goals, starting focus sessions and redeeming breaks.

### Cards
Used to display goals, points, progress and session history.

### Input Fields
Used for entering goal names, descriptions and focus durations.

### Navigation
Used to move between Dashboard, Goals, Focus, Progress and History.

### Points Display
Shows the points earned by users.

### Focus Timer
Displays the remaining time during a focus session.

### Progress Indicator
Shows completed goals and focus session progress.

### Feedback Messages
Displays success and error messages after user actions.

## 5. Screen-wise Component Usage

- Dashboard: Summary cards, points display and navigation.
- Create Goal: Input fields and buttons.
- Focus Session: Timer, progress indicator and controls.
- Redeem Break: Reward cards and redemption buttons.
- Progress: Progress indicators and summary cards.
- History: Session history cards.

## 6. Design Guidelines

- Maintain consistent colors and typography across screens.
- Use reusable components wherever possible.
- Keep layouts simple and easy to understand.
- Provide clear feedback after important user actions.
- Maintain sufficient spacing between UI elements.
