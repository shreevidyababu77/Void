# VOID

## About the Project

VOID is a free productivity and screen-time management platform that rewards users with points for completing productive activities.

The platform aims to help students reduce mindless scrolling, improve concentration and develop better productivity habits.

## Problem Statement

Students often spend excessive time scrolling through social media and consuming online content, which can affect their concentration, academic performance and mental well-being.

VOID encourages users to complete productive activities before taking planned breaks.

## Core Features

- Customizable productivity goals
- Focus timer
- Points system
- Break redemption using points
- Progress tracking
- Focus session history

## Technology Stack

- Next.js
- React
- JavaScript
- CSS
- React Context API
